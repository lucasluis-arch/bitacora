ArchivoGuardar en GitHub

Las fichas quedan en datos.json y cada portada como imagen en portadas/, en un repo tuyo. Así la biblioteca es la misma en el celular y en la compu.

Cómo crear el token (una sola vez)
  1. Creá un repo privado para los datos, por ejemplo bitacora-datos (distinto al de la página, así tus notas no quedan públicas).
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → ese repo.
  4. Repository permissions → Contents: Read and write.
  5. Copialo y pegalo acá. Queda guardado solo en este navegador; repetilo en cada dispositivo.
